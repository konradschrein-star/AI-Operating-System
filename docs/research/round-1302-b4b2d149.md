# Round 1302 — Google AI Ultra over OAuth: the five answers

Full findings, every citation and every raw probe body:
**[`docs/plan/operator-visibility/artifacts/phase1700/gemini-ultra-oauth.md`](../plan/operator-visibility/artifacts/phase1700/gemini-ultra-oauth.md)**
(same run, same sources). This page is the short form. All sources accessed **2026-08-17**.

## The five answers

1. **AUTH — there is no OAuth flow that gives an AI Ultra subscriber programmatic model access.**
   The one that used to, "Login with Google" for Gemini CLI / Code Assist, was switched off:
   *"Starting June 18, 2026, Gemini Code Assist IDE extensions stopped serving requests for the Gemini
   Code Assist for individuals, Google AI Pro, and Google AI Ultra tiers. This also applies to usage of
   Gemini CLI. As part of the deprecation, you can no longer use the Login with Google option…"*
   (https://developers.google.com/gemini-code-assist/resources/faqs, updated 2026-06-23).
   Konrad clicks **neither once nor twice** — adding `cloud-platform` to `/opt/ai-os/google-setup/setup.py`
   would be one re-consent on the same Desktop client (proven live: both `generativelanguage` and
   `cloudcode-pa` answered our existing token with `403 ACCESS_TOKEN_SCOPE_INSUFFICIENT`, not with
   "unknown client"), but it buys nothing Ultra-related and widens the box's most valuable credential.
   Recommend: don't.

2. **MODELS — verified by a real `models.list` call**, HTTP 200, 53 models.
   **`gemini-4.7-flash` does not exist**; no id containing "4.7" does. Newest Flash is
   **`gemini-3.7-flash`** (`version: 3.7-flash-08-2026`, 1,048,576 in / 65,536 out, `thinking: true`,
   `generateContent|countTokens|createCachedContent|batchGenerateContent`). Strongest servable:
   `gemini-3.1-pro-preview` (Preview, no free tier). **Video is a supported input modality** on the
   3.x line — the video-QA use case is fine at the API layer.

3. **USAGE/QUOTA — NO.** The v1beta discovery document (revision `20260814`) has no quota/usage/credits
   resource; the only "quota" hits are the standard `quotaUser` param. Google's own line is
   *"Rate limits … can be viewed in Google AI Studio"* — a dashboard, not an endpoint — and the
   rate-limits page never mentions Google One/Pro/Ultra at all. A `GOOGLE_ONE_AI` credits API does
   exist (`cloudcode-pa.googleapis.com/v1internal:loadCodeAssist` → `paidTier.availableCredits[]`), but
   it is undocumented `v1internal` **and** it is exactly the surface consumer accounts were cut off from
   in June. **Do not draw a percentage-of-Ultra bar.** Honest options, best first: our own spent-count
   per rolling 5h/7d with no denominator; or a cost bar from `usageMetadata` against real prices.

4. **GEMINI POOL — complement, keep as fallback.** Live: 4/4 sessions ready, up 18.9 days, mean response
   **46 s**, `/models` 404 (no model pinning). It is free and needs no billing; it cannot deliver the
   speed Konrad likes about Flash. Split: latency-sensitive and model-pinned work → API; bulk video QA →
   pool (which `scripts/gemini-qa.mjs` already defaults to).

5. **RATE/COST — "20x" is a consumer-product multiplier, not an API quota multiplier.** It applies to the
   Gemini app, AI Studio, Antigravity and Jules. The only Ultra→API bridge is money: a monthly Google
   Cloud credit. **Contradiction, reported not averaged:** one.google.com (undated) shows *"40 $
   monatliches Google Cloud-Guthaben"* while blog.google (2026-01-27) states *"$10 per month … for
   Google AI Pro subscribers and $100 per month for Google AI Ultra"*. I trust the $100 for Ultra — the
   blog names the tier split, the plans page does not. Hard-code neither.
   API prices, `gemini-3.7-flash`: **$0.75 in / $3.75 out per 1M through 2026-12-31, then $1.50 / $7.50**.
   Tier 1 caps spend at $250/mo and Tier 2/3 require aged cumulative spend (3 and 30 days) — a fleet hits
   the tier cap before it hits RPM, and capacity cannot be bought same-day.

## Recommended integration shape (one line each)

- Ship a **paste-in API key** field (`/opt/ai-os/.secrets/store/gemini-api-key`), validated by
  `GET /v1beta/models` with `x-goog-api-key`; default `gemini-3.7-flash`.
- Leave the existing Google OAuth (Gmail/Calendar/Drive) untouched.
- Gemini bar = **our own spend count, no denominator**, labelled as such.
- **Antigravity CLI** (`agy -p … --output-format json`, `--model`, `agy models`, quota via a TUI `/usage`
  panel) is the only surface that runs on the Ultra quota and it handles SSH login — evaluate later; its
  ToS says Google collects your Interactions data, which is Konrad's call, not a builder's.

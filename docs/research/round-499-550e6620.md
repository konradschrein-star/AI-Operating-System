# Round 499 Scout — Corpus claims about instrument-manifest and check-instrument-typecheck

**Project:** scripts-checks-typecheck-gate  
**Date:** 2026-08-18  
**Scope:** Recon for phase 5; identify all corpus references to `instrument-manifest` and `check-instrument-typecheck` that will need amendment when the gate's implementation changes.

---

## Findings

**Critical discovery:** The script header itself (check-instrument-typecheck.sh, lines 22-47) explicitly redefines what the gate does, contradicting multiple corpus claims. The key statement:

> "The round-800 gate read an INCLUSION LIST — `scripts/checks/instrument-manifest.txt` — and compiled the seven paths named in it, with a "manifest guard" that failed the run when a `scripts/checks/*.ts` file the branch had touched was absent from the list. Both are GONE" (lines 22-25).

This means:
- The gate **no longer** reads the manifest
- The gate **no longer** has a manifest guard that fails on missing files
- Enumeration is now by glob over the whole directory, not by reading the manifest

## Notes for Phase 5 Planner

- **Measurement authority:** The check-instrument-typecheck.sh script header (lines 22-100) is the authoritative description of what changed and why. It supersedes all prior claims in the corpus about manifest reading and manifest guards.

- **Historical markers:** Existing corpus sections describing round-800 behavior (e.g., "MEASURED AT ROUND 800", "The round-800 gate…") should be marked `[historical]` per the instrument-identity checker's protocol, not deleted.

- **Current behavior:** The gate now enumerates by glob, compiles all matching files through the profile, checks for suppression directives, and reports both type errors and uncovered/unmanifested files. The manifest no longer governs what is compiled; it documents exceptions.

- **Coverage scope:** The new gate compiles directory-wide (all scripts/checks/*.ts), not branch-diff-scoped. This is mentioned in the script header at lines 26-31 but not reflected in 03-quality.md §3.1 item 9's current explanation.

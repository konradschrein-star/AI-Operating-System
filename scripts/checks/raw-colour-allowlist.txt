# raw-colour-allowlist.txt — sibling data file for scripts/checks/no-raw-colours.cjs
#
# Format: FILE<TAB>EXTENDED-REGEX<TAB>ONE-LINE REASON
#   FILE    path relative to the repo root
#   REGEX   matched against the CONTENT of the hit line. A hit is excused only
#           if BOTH the file matches AND its own line matches — listing a file
#           does NOT blanket-excuse it. A new, different literal landing in an
#           already-listed file still fails the gate. Same contract as
#           dollar-allowlist.txt.
#   REASON  printed next to the hit. A reason beginning `TODO` marks
#           ACKNOWLEDGED DEBT rather than a legitimate carrier: those hits are
#           reported loudly in their own section on every run but do not fail
#           the gate, because they predate it and fixing all of them in one
#           round is the sprawl this guard exists to make unnecessary.
#
# Rules are matched in file order, first match wins — so a narrow "legitimate"
# rule must come BEFORE a broad TODO rule for the same file.
#
# Blank lines and lines starting with # are ignored.
#
# ── HOW TO RETIRE A TODO LINE ────────────────────────────────────────────────
# Replace the literals with tokens from forge-control-web/app/tokens.ts, adding
# the token to BOTH palettes in theme.css if it does not exist yet, then delete
# the line here. The gate will keep you honest: leave one literal behind and the
# file fails as UNLISTED.

# LEGITIMATE CARRIERS — a literal here is correct, not debt

forge-control-web/app/theme.css	^\s*--(fg|v2)-	The palette itself. Every hit in this file is a `--fg-*` / `--v2-*` custom-property DEFINITION for one of the two themes — this is the one place a hex is the point. Verified: the file contains no non-definition colour literal.
forge-control-web/app/v2.css	^\s*(--v2-|\.theme-[a-z]+\s)	The v2 layer's own custom-property definitions, including the `.theme-*` accent presets. Definitions, same as theme.css.
forge-control-web/app/tokens.ts	return "#000"	`resolveToken()`'s server-side fallback. There is no computed style on the server, so it returns an inert black rather than throwing into a render; documented at the call site.
forge-control-web/app/layout.tsx	themeColor	Next `metadata.themeColor` — the browser/OS chrome bar colour. It is emitted into a `<meta>` tag before any stylesheet resolves, so it cannot be a `var()`. Follow-up worth having: emit both, keyed on `prefers-color-scheme`, so the phone status bar follows the theme too.
forge-control-web/app/desktop/MemoryGraph3D.tsx	.*	three.js / WebGL. It paints into a GL context that never sees the CSS cascade, so it must carry its own palette — `tokens.ts` names this file explicitly as the reason `resolveToken()` exists. Its DOM-side tooltip HTML strings are part of the same self-contained palette.

# Format: FILE<TAB>EXTENDED-REGEX-PATTERN<TAB>ONE-LINE REASON
#   FILE     path relative to the repo root

#            primary-gate hit line in FILE. If a hit's content matches, it is
#            allowlisted; if not, it fails the gate even though the file is

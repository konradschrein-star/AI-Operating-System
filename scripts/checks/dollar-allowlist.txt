# dollar-allowlist.txt — sibling data file for scripts/checks/dollar-sweep.sh
#
# Format: FILE<TAB>EXTENDED-REGEX-PATTERN<TAB>ONE-LINE REASON
#   FILE     path relative to the repo root
#   PATTERN  an ERE (grep -E syntax) matched against the CONTENT of every
#            primary-gate hit line in FILE. If a hit's content matches, it is
#            allowlisted; if not, it fails the gate even though the file is
#            listed here (a new, different dollar hit in an already-listed
#            file is NOT silently waived). The pattern itself may use `|`
#            for alternation — TAB, not `|`, separates the three columns.
#   REASON   printed by the sweep script next to every hit it excuses.
#
# Blank lines and lines starting with # are ignored.
#
# See docs/plan/artifacts/phase400/dollar-allowlist.md for the full per-line
# table (file, line, snippet, reason) this file encodes as regexes.
